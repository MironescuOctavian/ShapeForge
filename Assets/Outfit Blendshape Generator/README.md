# ShapeForge
## Precision Blendshape Generator

Open Tools → ShapeForge → Blendshape Generator in Unity 6. Select the body mesh, outfit and source shape. Preview the fit and generate the blendshape for the selected pieces. Use Restore to remove generated shapes.

Barycentric is the default. Advanced contains Weighted, RBF and authored reference state options. Modular Avatar can synchronize sliders when installed.

See https://github.com/MironescuOctavian/ShapeForge for installation, compatibility and limitations.
