# ShapeForge
## Precision Blendshape Generator

Open Tools → ShapeForge → Blendshape Generator in Unity 6. Select the body mesh, outfit and source shape. Click Edit and look for ShapeForge Edit Mode in Unity’s Scene View. Use Edit Settings inside the ShapeForge panel to choose and adjust tools, save corrections, or discard the draft. Use Generator and Resume Edit to switch views while you work. Use Restore to remove generated shapes.

Barycentric is the default. Advanced contains Weighted and RBF. Modular Avatar can synchronize sliders when installed.

See https://github.com/MironescuOctavian/ShapeForge for installation, compatibility and limitations.
