# ShapeForge
## Precision Blendshape Generator

Open Tools → ShapeForge → Blendshape Generator in Unity 6. Select the body mesh, outfit and source shape. Click Edit and look for ShapeForge Edit Mode in Unity’s Scene View. Use the dockable ShapeForge Edit Settings window to adjust tools, save corrections, or discard the draft. Use Restore to remove generated shapes.

Barycentric is the default. Advanced contains Weighted and RBF. Modular Avatar can synchronize sliders when installed.

See https://github.com/MironescuOctavian/ShapeForge for installation, compatibility and limitations.
