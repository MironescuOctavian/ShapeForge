# ShapeForge
## Precision Blendshape Generator

Open Tools → ShapeForge → Blendshape Generator in Unity 6. Select the body mesh, outfit and source shape. Click Edit and look for ShapeForge Edit Mode in Unity’s Scene View. Edit starts in All Cloth. Use the cloth list in ShapeForge or the Scene View picker to limit tools to one piece. Use Vertex Control to select and move a patch or straighten a strip with three surface clicks. Choose End Edit for a clean session or Save Corrections or Discard when changes are pending. Use Back and Resume Edit to switch views while you work. Use Restore to remove generated shapes.

Barycentric is the default. Advanced contains Weighted and RBF. Modular Avatar can synchronize sliders when installed.

See https://github.com/MironescuOctavian/ShapeForge for installation, compatibility and limitations.
