# ShapeForge
## Precision Blendshape Generator

Open Tools → ShapeForge → Blendshape Generator in Unity 6. Select the body mesh, outfit and source shape. Open the Fit Editor to inspect and correct the fit, then save the blendshape for the selected pieces. Use Restore to remove generated shapes.

Barycentric is the default. Advanced contains Weighted and RBF. Modular Avatar can synchronize sliders when installed.

See https://github.com/MironescuOctavian/ShapeForge for installation, compatibility and limitations.
