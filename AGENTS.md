# ShapeForge development instructions

ShapeForge specializes exclusively in blendshape generation and correction for garments authored for the same avatar. Prioritize automatic transfer accuracy over additional features. Never overwrite original meshes or purchased source assets. Preserve original bone weights by default. Keep Unity 6 compatibility and keep the implementation maintainable and lightweight.

Run relevant checks after completed changes. Commit each completed, coherent development task with a descriptive message. Use main for ongoing development and commit verified changes there unless the user requests another branch. Push completed commits to main when authorized and authenticated. Never stage unrelated files or secrets. Never force-push or overwrite another person's changes. Report commit hashes and verification results. Stop and report blocked Git operations instead of claiming success.
